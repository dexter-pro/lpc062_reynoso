# Proyectos de Ciberseguridad y Automatización

Este repositorio reúne diferentes proyectos desarrollados durante mi formación en Seguridad en Tecnologías de Información.

El objetivo de estos ejercicios fue aplicar conceptos de programación, scripting, redes y automatización a diferentes escenarios relacionados con ciberseguridad.

## Contenido del repositorio

### PowerShell

Ejercicios de automatización utilizando PowerShell para interactuar con el sistema operativo Windows y realizar diferentes tareas administrativas.

### Bash

Scripts desarrollados para practicar automatización y administración de sistemas Linux mediante Bash.

### Web Scraping

Ejercicios enfocados en la extracción y procesamiento automatizado de información disponible en sitios web.

### Escáner de puertos

Herramienta desarrollada para identificar puertos accesibles en un host y practicar conceptos relacionados con redes y reconocimiento.

### Envío de correos

Scripts para automatizar el envío de correos electrónicos utilizando programación.

## Tecnologías utilizadas

- Python
- PowerShell
- Bash
- Linux
- Windows
- Redes TCP/IP

## Objetivo

Este repositorio representa parte de mi aprendizaje práctico en ciberseguridad y demuestra el uso de diferentes lenguajes y herramientas para resolver tareas relacionadas con automatización, redes y administración de sistemas.
